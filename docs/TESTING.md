# Testing · KraicDev

The exact release-binary results are in [validation/V060-RESULTS.md](validation/V060-RESULTS.md) (previous: [V050](validation/V050-RESULTS.md)); historical/private runs are not substitutes. The measured comparison with Display Driver Uninstaller, with scripts and data, is in [COMPARISON-DDU.md](COMPARISON-DDU.md).

Run scripts/Test.ps1 for logic and build checks. scripts/Build.ps1 runs logic tests before self-contained single-EXE publication. Test-only WPF audit: Swap.exe --ui-audit=C:\SwapUiAudit; it uses DemoPlatform and DemoCleanupPlatform and never performs real driver changes.

Coverage includes all six NVIDIA/AMD/Intel directions, integrated GPU preservation, hardware ID boundaries, catalog ranking, upgrades/OEM protection, pending reboot/remote/admin/incomplete inventory blocks, signed driver/PnP/version verification, backup/export/install/cleanup failures, cancellation, concurrency, hot-plug, continuation and final-state drift.

Disconnected-device handling: install, no-offer maintenance and restart continuation remove the disconnected old GPU before its package, refuse a disconnected device of another brand and stop without deleting when Windows keeps the device. Automatic mode keeps the processor brand's display packages unless that brand is chosen.

Deep cleanup: INF model parsing, command-line file extraction, processor integrated-graphics heuristics, exact provider names, NVIDIA→AMD ownership with AMD chipset untouched, Intel cleanup that keeps network/platform packages, connected-brand refusal, active/mixed packages, PhysX protection, services/tasks/startup/apps rules, AMD installer folders, older-version selection; engine ordering (process → device → package), backup-before-delete for every reversible kind, quarantine sealing, undo, unselected items, dependencies, device/package/export failures, reconnected brand, other machine, session validation, tampered undo manifest and quarantine, cancellation, unsafe folders and junctions. PCIe width and idle-speed handling.

Files, registrations and games (0.6): INF copies to System32/SysWOW64 and AddComponent IDs, setup-log `Copying`/`Hardlinking` lines, file authors (including ATI), package-evidence and shared-runtime rules, files Windows already removed, Khronos registrations and overlay layers, COM codecs with Media Foundation and `PnpResources` entries, PnP protection entries, quarantine with integrity and undo, tampered quarantined files, software components of a removed display driver; Direct3D 12/Vulkan/OpenCL evaluation and stale runtimes; card-change detection (waiting, swapped, no GPU, several GPUs, other PC, invalid preparation); English validation report without account or computer names. `Swap.Tests.exe --api-probe-readonly` runs the real child-process API check (read-only).

Independent-backup tests cover Display-only export, no driver mutations, altered/added/missing files, nested manifest names, malicious manifest paths, incomplete/admin/duplicate inventory rejection, export failures and cancellation. Manifest hashes are integrity metadata, not publisher authentication; signatures are checked separately.

Native guest checks cover inventory, graphics APIs/events and temporary RunOnce register/remove. `--logon-task-lab=<Swap.exe>` (elevated) registers a real sign-in task, checks it in Task Scheduler and the protected copy's hash and ACL (no write access beyond administrators and SYSTEM), then removes it. `--cleanup-preview=<vendor>` (elevated, read-only) prints what the deep cleanup would remove and keep if that brand's card were taken out of this PC, without changing anything. `Swap.Tests.exe --deep-clean-lab=<folder with nv*.inf packages>` is a destructive lab check restricted to the isolated `SWAPTESTVM` guest: it stages real signed NVIDIA packages with no NVIDIA hardware, creates vendor-like services, a task, a startup entry, a Programs entry, folders, settings and a running process, runs deep cleanup with the real Windows platform, checks the administrator-only backup ACL, then undoes it and checks the restoration. `--amd-cleanup-lab=<folder>` and `--undo-lab=<session>` are the comparison-lab modes (isolated guest only): Swap's default cleanup of a removed AMD card with the real Windows platform, and its undo. The WPF audit covers 144 combinations of six languages, two themes, two sizes and six pages; three full simulated workflows; deep cleanup run and undo; refresh-rate apply and revert; checkpoint/disclosures; independent backup; diagnostic-report export with the executable version; the games panel before and after a driver; and the full simulated card change (prepare, detect, a first install that fails as if Windows were busy, the automatic retry, clean, report) with the banner checked in Spanish and German at the narrow size. It checks layout and excessive Home/Settings scroll at the wide size, not every DPI or monitor configuration.

Before a stable release: validate physical GPU replacement in each vendor direction, same-vendor upgrades, OEM/hybrid laptops, real Windows Update downloads/install/removal, deep cleanup after real vendor suites (NVIDIA App, AMD Software, Intel Graphics Software), interruption/recovery, interactive restart continuation, Windows 11, and representative games/display/audio configurations. Record hardware/OS/version/hash and each outcome. Do not test privileged driver changes on a user's working remote PC.

A successful build or VM render is not evidence of real driver safety or game stability. No zero-error or universal compatibility claim is made.
