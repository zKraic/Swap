# Repository and releases

KraicDev · Swap · GPL-3.0-or-later.

Official repository: https://github.com/zKraic/Swap . Source and contributor documentation are on main. The previous local 0.3.0 delivery and private lab data remain outside the initial public repository.

Previews include a tagged source, single portable EXE, SHA-256, runtime notices and an exact-binary validation report. They are not stable releases or physical GPU/game certification. Diagnostics require neither installation nor a reboot.

Pull-request CI builds/tests without publication or signing secrets. Releases require maintainer review and exact-artifact validation. Trusted signatures require external approval; see SIGNING.md.

Never publish artifacts, Data, VM disks/hives, unattended credentials, downloaded tools, driver packages, certificates or historical local binaries. Source ZIPs are developer downloads; the application itself is an EXE.

Announcements must identify the maintainer, experimental/signing status and untested physical operations, and follow each community's rules. Do not claim universal safety or endorsements. Do not submit automated promotional text to communities that prohibit it.
