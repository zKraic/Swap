# Security · KraicDev

Report security concerns privately through this repository's **Security → Report a vulnerability** when enabled. Do not post exploit details, private logs or machine identifiers in a general issue. If private reporting is unavailable, contact the maintainer through their GitHub profile before disclosing details.

Only the latest release is maintained. It was validated on one real card change and in isolated Windows guests; that is evidence, not a certification of every GPU, game or system, and trusted code signing is still pending. Read docs/SECURITY.md for safeguards and limits. Swap is GPL-3.0-or-later; manufacturer drivers retain their own licenses and are not redistributed.
